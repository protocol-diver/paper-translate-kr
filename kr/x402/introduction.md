x402 는 HTTP 를 통해 API 및 콘텐츠 접근에 대해 직접 요금을 부과할 수 있도록 하는 개방형 결제 표준입니다. HTTP 상태 코드 `402 Payment Required` 를 기반으로 하며, 계정, 세션, 또는 자격 증명 관리 없이도 클라이언트가 프로그래밍 방식으로 리소스에 대한 비용을 지불할 수 있게 합니다.
x402 를 사용하면 어떤 웹 서비스든 응답을 제공하기 전에 결제를 요구할 수 있으며, 빠르고 프라이버시 친화적이며 효율적인 암호화폐 기반 결제를 활용합니다.

**문서에 기여하고 싶으신가요?** [GitBook 저장소는 PR을 열 수 있도록 공개되어 있습니다! ](https://github.com/x402-foundation/x402) 단, 이 문서는 중립적인 자료로 유지되어야 하며, 특정 브랜드 홍보 콘텐츠는 포함하지 않고 필요한 경우 외부 리소스 링크만 허용됩니다.

**문서 관련 안내:** 이 문서는 x402 의 신뢰할 수 있는 중립적 기준 자료입니다. x402 는 Apache-2.0 라이선스 하에 완전히 개방된 표준입니다. 현재 Coinbase Developer Platform 이 사용자용 [AI 기반 문서](https://docs.cdp.coinbase.com/x402/welcome)를 후원하고 있으며, 향후 x402.org 메인 도메인에서 자체 AI 문서 시스템으로 이전할 예정입니다.

### Why Use x402?

x402 는 다음과 같은 장점을 제공합니다:

- **수수료 없음 및 낮은 마찰 비용**: x402 표준 자체에는 수수료가 포함되어 있지 않습니다.
- **머신 간 결제(M2M) 네이티브 지원**: AI 에이전트가 자연스럽게 사용할 수 있습니다.
- **내장된 마이크로 결제 지원**: 사용량 기반 서비스 수익화를 쉽게 구현할 수 있습니다.

### Who is x402 for?

- **판매자(Sellers):** API 또는 콘텐츠를 수익화하려는 서비스 제공자. x402는 최소한의 설정으로 클라이언트로부터 직접 프로그래밍 결제를 받을 수 있게 합니다.
- **구매자(Buyers):** 계정이나 수동 결제 과정 없이 유료 서비스를 이용하려는 개발자 및 AI 에이전트.

판매자와 구매자는 HTTP 요청을 통해 직접 상호작용하며, 결제는 프로토콜을 통해 투명하게 처리됩니다.

### What Can You Build?

x402 를 활용하면 다음과 같은 다양한 사용 사례를 구현할 수 있습니다:

- 요청당 과금되는 API 서비스
- API 접근 비용을 자동으로 지불하는 AI 에이전트
- 디지털 콘텐츠를 위한 [Paywalls](https://x.com/MurrLincoln/status/1935406976881803601)
- 마이크로트랜잭션 기반 마이크로서비스 및 도구
- 여러 API 기능을 통합하고 재판매하는 프록시 서비스

### How Does It Work?

전체 흐름은 다음과 같습니다:

1. 구매자가 서버에 리소스를 요청합니다.
2. 결제가 필요한 경우, 서버는 `402 Payment Required` 응답과 함께 결제 정보를 반환합니다.
3. 구매자는 결제 페이로드를 준비하여 제출합니다.
4. 서버는 결제를 직접 검증 및 정산하거나, x402 중개자의 `/verify` 및 `/settle` 엔드포인트를 활용할 수 있습니다.
5. 결제가 유효하면 서버는 요청한 리소스를 제공합니다.
